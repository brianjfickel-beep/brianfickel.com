Visitors to this site

This site uses no cookies, analytics, advertising or tracking, and it has no accounts or forms. The practitioner tools run entirely in your browser: what you type or paste is never sent to or stored by this site. The site is hosted on GitHub Pages, which may log visitors' IP addresses for security under the GitHub Privacy Statement. Fonts load from Google Fonts, which receives your IP address under Google's privacy policy. If you email me, I use your message only to reply.

Fickel Gmail Reader

Fickel Gmail Reader is a personal tool written and operated by Brian Fickel for his own use. It is not offered to the public, and its only user is its owner.

What it accesses

With the owner's consent through Google sign-in, the tool uses the read-only Gmail scope (gmail.readonly) to read messages and download attachments from the owner's own Gmail account. It cannot send, delete or change email.

How data is used and stored

Downloaded attachments and message details are saved only to the owner's personal computer and personal cloud storage, to organize the owner's own files. The access token is stored locally on that computer. No data is sold, shared with third parties, used for advertising or used to train machine-learning models.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by the owner at any time.
